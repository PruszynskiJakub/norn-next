115:**Upgrading a repository set up by an older norn?** It keeps its config, workflows and trace together in one folder under `.agents/`; on that layout every command refuses and names `norn migrate`. Run `norn migrate` in the main checkout, with `norn watch` stopped: it moves the config and workflows to their new places as staged git moves, moves the trace to this machine's folder for the checkout, and prints the commit to make. Once that commit merges, an older norn cannot read the repository: upgrade norn on every machine that works on it.
