norn run — The runs of a unit: its step timeline, one run, why a tick decided what it did, its agent pane; rerun or cancel it

  norn run list    Step timeline of a unit: durations, outcomes, who, reasons; a story with its slices
  norn run view    One run of a unit: step, attempt, outcome, durations, receipts; --why replays the decision
  norn run attach  Focus the Herdr agent pane of a unit's live run; --next: the oldest one waiting for you
  norn run rerun   Resume a stuck, parked or gate-waiting unit in a fresh session, optionally --step elsewhere and --reset counters
  norn run cancel  Stop a unit's running agent session; the story and its work stay (rerun resumes it)

norn status — What needs you, grouped by action, with the command to resolve each item; --history for when items came and went

    norn status [--json] [--details] [--notes] [--history [--since <iso|duration>]] | norn status --watch [--interval 5s] [--pane]

Options
  --details                           each item's full text
  --notes                             list the open notes, not one summary line
  --history [--since <iso|duration>]  every item that needed you, with when it came and went
  --watch                             the live cockpit full screen: act on items by key, q or Esc quits
  --interval <duration>               with --watch: how often it refreshes (default 5s)
  --pane                              with --watch: run it in a Herdr pane split below this one

For the person; an agent runs it only when the person asks it to.
norn story — The stories of this repository

General
  norn story create         Create a story's issue on the remote, assigned to you, and take it in
  norn story list           Stories, slices, runs and claims at a glance
  norn story view           One story: slices with their steps, the PR, open notes, what waits for you; --web opens the PR or issue

Decision
  norn story answer         Answer the question a unit is parked on; a prompt in an agent's pane gets the keys it expects
  norn story approve        Approve the gate a unit waits at
  norn story reject         Reject the gate a unit waits at, with the reason the next attempt gets
  norn story update-branch  Send a waiting story back through its base update: done with an unmerged PR, at a gate, or stuck

Work
  norn story start          Open an agent on the step a person starts: a Herdr tab in the unit worktree, or the command to run
  norn story chat           Give a story its own Herdr workspace with an agent to talk it over
  norn story edit           Switch a story between auto and manual mode, or choose a unit's workflow

Team
  norn story checkout       Take a story over on this machine: claim it, check out its branches, print the handoff
  norn story handoff        Hand a story over: push branches and handoff, then delete the claim
  norn story close          Close a story: push its branches, then remove worktrees, local branches and the claim; the record, issue and PR stay
  norn story reopen         Undo a close: claim the story here, restore its worktrees and put each unit back at its step

`norn help story <verb>` shows one verb's usage and options.
