# Throwaway repo
Built by gh-107/03's `scripts/trace-bench.ts` (taken from the story branch with `git show`; 03 is not merged into this slice's branch), copied to `bench/scripts/trace-bench.ts` with two changes (diff: compare `bench/trace-bench.ts`): the live run's 420 hook facts are also written to its unit hook file `trace/hooks/gh-1/_story.jsonl` (as `norn hook` does on this branch), and `brief` is timed 5 times (median). It sets up repo + unit worktree `gh-1-long-step` (marker, live `implement` run), 14 day files totalling 2.15 GB. Every command runs the code under QA: `bun <worktree>/packages/cli/src/main.ts`, with NORN_HOME_DIR pointing into the throwaway dir. Scripts: manual.sh, ac1trace.sh, ac6.sh, ac45.sh, ac4b.sh.
"Day files unreadable" = `chmod 200` on `trace/YYYY-MM-DD.jsonl` (append works, any read fails with EACCES; `chmod 000` showed that `brief` opens today's file only to append its `briefing` event).
