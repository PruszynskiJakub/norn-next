## AC2: the rule covers only noticeable behaviour, and review's Standards axis can flag a breach (agent)

**Read:** `AGENTS.md` Rules › Docs, and `packages/pack-sdlc/assets/skills/norn-review/SKILL.md`.

**Saw:**
- The rule says: "It covers only behaviour someone can notice: a refactor, a test-only change or an internal rename with no visible change needs no doc and draws no finding. A visible behaviour change with no docs diff and no reason given is a breach of this rule."
- In norn-review, the Standards axis gathers "whatever the repo documents … (`CLAUDE.md`, `AGENTS.md`, …)" and covers "Breaches of a documented standard, citing the rule". So a missing docs diff with no reason is a citable `AGENTS.md` breach, and a refactor is explicitly excluded.

**Verdict: pass**
