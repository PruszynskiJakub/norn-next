```
{

  "start": "a",
  "steps": {
    "a": {

      "skills": [
        "x"
      ],
      "by": "codex",
      "outcomes": {
        "done": { "to": "$done", "counter": "c" },   <- printed expanded, 2-space
```

where `skill`/`agent` were, means/verdict right after outcomes). Re-translation unchanged.
